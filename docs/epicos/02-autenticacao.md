# Épico 2 - Autenticação

## Descrição

Integração com login via conta institucional Office 365

## Requisitos vinculados

- **RF06**: O sistema deve permitir login exclusivamente via conta institucional Office 365
- **RF07**: O sistema deve restringir o acesso a usuários autenticados com vínculo à UnB
- **RF08**: O sistema deve diferenciar os papéis de aluno e professor após a autenticação, liberando as funcionalidades correspondentes a cada perfil
- **RNF03**: O acesso à plataforma deve ser restrito a usuários com conta institucional válida (Segurança)

## Histórias de usuário

- **HU-02.01**: Login institucional
- **HU-02.02**: Diferenciação de papéis
- **HU-02.03**: Restrição de acesso
- **HU-02.04**: Sessão e logout
- **HU-02.05**: Primeiro acesso
