# HU-01.01: Criar perfil de aluno

**Ator Principal:** Aluno do departamento de Ciência da Computação da UnB<br>
**Módulo do Sistema:** Módulo de Perfil<br>
**Épico:** Épico 1 — Perfis<br>
**Pré-condição:** Épico 2 (Autenticação via Office 365)

---

### 1. Descrição Narrativa
> **Como** aluno do departamento de Ciência da Computação da UnB,<br>
> **Gostaria de** criar meu perfil na plataforma Linka após meu primeiro acesso institucional,<br>
> **Para** buscar oportunidades de iniciação científica e pesquisa acadêmica compatíveis com meu perfil.

---

### 2. Checklist de Componentes da Interface (UI/UX)
#### Dados pré-preenchidos automaticamente (vindos do login institucional — Épico 2, não editáveis)
- [ ] Exibição do nome completo do aluno
- [ ] Exibição do e-mail institucional (@aluno.unb.br)
- [ ] Exibição da matrícula do aluno
- [ ] Curso
- [ ] Período atual
- [ ] Nível de formação (Graduação / Mestrado / Doutorado)
#### Dados de contato (pelo menos um obrigatório)
- [ ] Campo: E-mail de contato alternativo (pode ser diferente do institucional)
- [ ] Campo: Telefone para WhatsApp (formato validado com máscara)
#### Perfil acadêmico (opcionais, mas estratégicos para o Épico 3 — Busca)
- [ ] Campo: Habilidades técnicas (tags livres — ex: Python, React, LaTeX)
- [ ] Campo: Link do currículo Lattes (validado se preenchido)
- [ ] Campo: Link do LinkedIn (validado se preenchido)
- [ ] Campo: Indicativo de disponibilidade para participar de oportunidades de pesquisa (Open to)
#### Áreas de interesse (obrigatório selecionar ao menos uma)
Seleção múltipla com opções pré-cadastradas, como por exexmplo:
- [ ] Inteligência Artificial e Machine Learning
- [ ] Computação Teórica
- [ ] Engenharia de Software
- [ ] Segurança da Informação
- [ ] Interação Humano-Computador
- [ ] Desenvolvimento de Jogos
- [ ] Desenvolvimento Web e Mobile
- [ ] Banco de Dados
- [ ] Outras (com campo de texto livre)
#### Elementos de UX
- [ ] Indicador de progresso do formulário (ex: barra ou etapas "1 de 3")
- [ ] Botão "Salvar e continuar" ao fim de cada etapa
- [ ] Feedback de erro (mensagens inline) para preenchimento incorreto de qualquer campo
- [ ] Tela de confirmação ao final com resumo do perfil criado e botão "Ir para meu perfil"
### 3. Critérios de Aceitação (Regras de Negócio e Validações)
#### Fluxo Principal (Sucesso):
* **Cenário 1: Criação de perfil com dados válidos**
- **Dado** que o aluno acessou a plataforma pela primeira vez via conta institucional (Office 365),
- **Quando** ele preencher todos os campos obrigatórios corretamente e acionar "Confirmar",
- **Então** o sistema deve persistir o perfil, gerar um identificador único, exibir a tela de confirmação e tornar o perfil visível na plataforma.
* **Cenário 2: Redirecionamento automático no primeiro acesso**
- **Dado** que o aluno autenticou via Office 365 e ainda não possui perfil criado,
- **Quando** o login for concluído,
- **Então** o sistema deve redirecioná-lo automaticamente para o fluxo de criação de perfil, sem necessidade de navegação manual.

#### Fluxo de Exceção (Validações e Tratamento de Erros):
* **Cenário 1: Conta institucional inativa ou inválida**
- **Dado** que o aluno tentou autenticar com uma conta sem vínculo ativo no departamento,
- **Quando** o sistema verificar o status junto ao provedor institucional (Épico 2),
- **Então** o acesso deve ser bloqueado com mensagem: "Sua conta institucional não possui vínculo ativo. Entre em contato com a secretaria do CIC."
* **Cenário 2: Campos obrigatórios não preenchidos**
- **Dado** que o aluno tentou avançar ou confirmar o formulário,
- **Quando** houver campos obrigatórios em branco,
- **Então** o sistema deve destacar os campos pendentes com erro inline e impedir o avanço sem bloquear os dados já preenchidos.
* **Cenário 3: Formato inválido em campos com validação**
- **Dado** que o aluno preencheu o campo de telefone ou link (Lattes/LinkedIn) com formato incorreto,
- **Quando** o campo perder o foco ou o formulário for submetido,
- **Então** o sistema deve exibir mensagem de erro específica por campo (ex: "Link do Lattes inválido. Use o formato: lattes.cnpq.br/...").
