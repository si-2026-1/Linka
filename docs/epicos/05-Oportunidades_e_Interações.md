# Épico 5 — Oportunidades e Interações

## Descrição

Fluxo de publicação de oportunidades em projetos por professores, permitindo que alunos demonstrem interesse, interajam com as publicações e recebam notificações básicas sobre comentários, reações ou mensagens relacionadas às vagas.

## Requisitos vinculados

- **RF15**: O sistema deve permitir que professores publiquem vagas em projetos.
- **RF16**: O sistema deve permitir que alunos reajam a publicações de vagas como forma de demonstrar interesse.
- **RF17**: O sistema deve permitir uma comunicação mínima entre os usuários envolvidos nas oportunidades.
- **RF18**: O sistema deve notificar os usuários sobre novos comentários em suas publicações ou novas mensagens recebidas.
- **RNF07**: O sistema deve restringir a publicação de vagas apenas a usuários com perfil de professor.
- **RNF08**: O sistema deve garantir que as notificações sejam entregues de forma clara e sem impactar negativamente a experiência de uso da aplicação.
- **RNF09**: O sistema deve restringir comunicação somente a professores e alunos

## Histórias de usuário

- **HU-04.01**: Publicação de vagas por professores.
- **HU-04.02**: Demonstração de interesse em uma publicação de vaga.
- **HU-04.03**: Comunicação entre usuários vinculados a uma oportunidade.
- **HU-04.04**: Notificações sobre interações, comentários e mensagens.
