# HU-03.01: Buscar por oportunidades

**Ator Principal:** Aluno, Professor, Visitante<br>
**Módulo do Sistema:** Módulo de Busca<br>
**Épico:** Épico 3 — Busca e Descoberta<br>
**Pré-condição:** N/A (A busca é uma funcionalidade pública)

---

### 1. Descrição Narrativa
> **Como** um usuário da plataforma (aluno, professor ou visitante),<br>
> **Gostaria de** realizar uma busca por palavras-chave,<br>
> **Para** encontrar oportunidades de pesquisa e iniciação científica de meu interesse.

---

### 2. Checklist de Componentes da Interface (UI/UX)
#### Elementos da Página de Busca
- [ ] Campo de texto (barra de busca) visível e de fácil acesso.
- [ ] Botão "Buscar" para iniciar a pesquisa.
- [ ] A busca também deve ser acionada ao pressionar a tecla "Enter" no campo de texto.
#### Página de Resultados
- [ ] Exibição de uma lista de cards, cada um representando uma oportunidade encontrada.
- [ ] Cada card deve conter: Título da oportunidade, nome do professor responsável, e um resumo breve.
- [ ] Paginação dos resultados caso a busca retorne um grande número de oportunidades.
- [ ] Mensagem clara (ex: "Nenhuma oportunidade encontrada para 'sua busca'") caso a pesquisa não retorne resultados.
- [ ] O termo buscado deve ser mantido no campo de busca na página de resultados.

---

### 3. Critérios de Aceitação (Regras de Negócio e Validações)
#### Fluxo Principal (Sucesso):
* **Cenário 1: Busca com resultados**
- **Dado** que o usuário está na página de busca ou na home,
- **Quando** ele digita um termo (ex: "Inteligência Artificial") e aciona a busca,
- **Então** o sistema deve exibir uma lista de oportunidades cujo título ou descrição contenham o termo pesquisado.
* **Cenário 2: Busca sem resultados**
- **Dado** que o usuário está na página de busca,
- **Quando** ele digita um termo que não corresponde a nenhuma oportunidade,
- **Então** o sistema deve exibir a mensagem "Nenhuma oportunidade encontrada".

#### Fluxo de Exceção (Validações e Tratamento de Erros):
* **Cenário 1: Busca em branco**
- **Dado** que o usuário acionou a busca sem digitar um termo,
- **Quando** a página de resultados for carregada,
- **Então** o sistema deve exibir todas as oportunidades ativas, ordenadas pela data de publicação (mais recentes primeiro).

---

### 4. Impacto Estrutural e Arquitetura de Dados
* **Coleções/Entidades Afetadas:** `oportunidades`
* **Considerações:** A busca deve ser otimizada para performance, utilizando índices no banco de dados nos campos de texto (título, descrição).
