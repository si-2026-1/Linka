# HU-03.02: Aplicar filtros na busca de oportunidades

**Ator Principal:** Aluno, Professor, Visitante<br>
**Módulo do Sistema:** Módulo de Busca<br>
**Épico:** Épico 3 — Busca e Descoberta<br>
**Pré-condição:** O usuário está na página de resultados de uma busca por oportunidades (HU-03.01).

---

### 1. Descrição Narrativa
> **Como** um usuário da plataforma,<br>
> **Gostaria de** aplicar filtros na minha busca por oportunidades,<br>
> **Para** refinar os resultados e encontrar vagas mais alinhadas ao meu interesse.

---

### 2. Checklist de Componentes da Interface (UI/UX)
#### Painel de Filtros
- [ ] Seção de filtros claramente identificada na página de resultados.
- [ ] Filtro por "Área de Conhecimento" (seleção múltipla com as áreas pré-cadastradas).
- [ ] Filtro por "Professor Responsável" (campo de texto com autocompletar).
- [ ] Filtro por "Tipo de Vaga" (ex: Iniciação Científica, Monitoria, Projeto de Extensão).
- [ ] Botão "Aplicar Filtros" para atualizar a lista de resultados.
- [ ] Botão "Limpar Filtros" para remover todas as seleções.
- [ ] Indicador visual para os filtros que estão ativos.

---

### 3. Critérios de Aceitação (Regras de Negócio e Validações)
#### Fluxo Principal (Sucesso):
* **Cenário 1: Aplicar um filtro com sucesso**
- **Dado** que o usuário está visualizando uma lista de resultados de busca,
- **Quando** ele seleciona uma "Área de Conhecimento" (ex: "Engenharia de Software") e aciona "Aplicar Filtros",
- **Então** o sistema deve atualizar a lista, exibindo apenas as oportunidades que correspondem à área selecionada e ao termo buscado originalmente.
* **Cenário 2: Combinar múltiplos filtros**
- **Dado** que o usuário está na página de resultados,
- **Quando** ele filtra por "Área de Conhecimento" E por "Professor Responsável",
- **Então** o sistema deve exibir apenas as oportunidades que satisfaçam AMBOS os critérios.
* **Cenário 3: Limpar filtros**
- **Dado** que o usuário aplicou um ou mais filtros,
- **Quando** ele aciona "Limpar Filtros",
- **Então** o sistema deve remover todos os filtros e reexibir a lista de resultados da busca original.

#### Fluxo de Exceção (Validações e Tratamento de Erros):
* **Cenário 1: Filtro sem resultados**
- **Dado** que o usuário aplicou um filtro,
- **Quando** não houver nenhuma oportunidade que corresponda à combinação de busca e filtro,
- **Então** o sistema deve exibir a mensagem "Nenhum resultado encontrado para os filtros aplicados".

---

### 4. Impacto Estrutural e Arquitetura de Dados
* **Coleções/Entidades Afetadas:** `oportunidades`, `professores`, `area_pesquisa`
* **Considerações:** A consulta ao banco de dados deve ser capaz de lidar com múltiplos filtros combinados de forma eficiente.
