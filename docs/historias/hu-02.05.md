# HU-02.05: Primeiro acesso

**Ator Principal:** Aluno ou Professor do departamento de Ciência da Computação da UnB

**Módulo do Sistema:** Módulo de autenticação

---

### 1. Descrição Narrativa
> **Como** usuário acessando a plataforma Linka pela primeira vez,  
> **Gostaria de** ter meu perfil inicial criado automaticamente com os dados da minha conta institucional,  
> **Para** não precisar preencher informações básicas manualmente do zero.

---

### 2. Checklist de Componentes da Interface (UI/UX)
- [ ] Tela de boas-vindas ao primeiro acesso
- [ ] Exibição dos dados preenchidos automaticamente (nome, e-mail, papel)
- [ ] Formulário para complementar as informações restantes do perfil
- [ ] Indicação de progresso de preenchimento do perfil (ex: "Perfil 40% completo")

---

### 3. Critérios de Aceitação (Regras de Negócio e Validações)

#### Fluxo Principal (Sucesso):
* **Cenário 1: Criação automática de perfil**
  * **Dado** que o usuário está autenticando pela primeira vez na plataforma,
  * **Quando** o login for concluído com sucesso,
  * **Então** o sistema deve criar automaticamente um registro de `Usuario` e `Perfil` com nome, e-mail e papel extraídos do token OAuth.

#### Fluxo de Exceção (Validações e Tratamento de Erros):
* **Cenário 2: Prevenção de perfil duplicado**
  * **Dado** que o usuário já possui um perfil cadastrado na plataforma,
  * **Quando** ele realizar um novo login,
  * **Então** o sistema não deve criar um novo perfil, apenas atualizar `data_ultimo_acesso`.
* **Cenário 3: Dados insuficientes retornados pelo OAuth**
  * **Dado** que o token retornado pela Microsoft não contém todas as informações esperadas,
  * **Quando** o perfil inicial for criado,
  * **Então** o sistema deve criar o perfil com os dados disponíveis e sinalizar os campos pendentes para preenchimento manual.
* **Cenário 4: Perfil incompleto**
  * **Dado** que o usuário não concluiu o preenchimento do perfil após o primeiro acesso,
  * **Quando** ele acessar a plataforma novamente,
  * **Então** o sistema deve exibir um aviso indicando que o perfil está incompleto e sugerir a conclusão do cadastro.

---

### 4. Impacto Estrutural e Arquitetura de Dados

* **Entidades Afetadas:** `Usuario`, `Perfil`
* **Atributos Modificados/Atualizados:**
  * `Usuario.data_primeiro_acesso`: preenchido automaticamente no momento da criação.
  * `Perfil.completo`: criado como `false` e atualizado para `true` quando todos os campos obrigatórios forem preenchidos.
  * `Perfil.data_criacao`: registrado automaticamente no primeiro acesso.
